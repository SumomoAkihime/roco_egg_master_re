## 转换过程

源数据按本项目 `pets_data.json` 格式调整：将各系中文名称标准化、蛋组转换为项目枚举、将 WIKI 页面数值映射为六维属性、将身高体重区间拆分为浮点数，并保留来源页面地址。

游戏配置 ID **不是** 图鉴编号。通过多个 lkmerchant 页面 URL 对照确认编号区间和部分特殊配置：
- 467/468 使用配置 3784/3785。
- 469–477 使用 3797–3805。
- 478 为两种形态：3806 柠檬鲨、3807 虎纹鲨。
- 479–492 使用 3808–3821。
- 493 阿布使用旧的 3168。
- 494–496 使用 3822–3824。

其中 **480、486、489** 的配置编号仅根据邻近已核对页面的连续编号暂时推定，标记为待游戏封包验证，不应宣称全部映射已通过游戏实测。

WIKI 页面显示部分 S5 精灵“蛋组：未发现”，在数据中记为**未知/空数组**，不把“未发现”错误解释成确定“不能孵蛋”。规划算法对未知蛋组精灵跳过计算。

## 数据边界

- 新 S5 精灵图鉴 **467–496 已纳入**，但不保证未来新增赛季增量、所有特殊形态、异色外观、炫彩模型和蛋的详细参数全部更新。
- 游戏配置 ID 映射来自公开资料，不代表 S5 客户端封包中的字段已真实验证。
- 异色排窝只给出蛋组/性别候选和理论传递路线，真实遗传概率与隔窝/串窝机制未验证。
- 新精灵图片尚未包含，应用可能显示占位图；第三方图片另有版权限制。
- 每次补数据需保留来源与相应许可说明，并通过 `node --test tests/s5Catalog.test.cjs` 和整体构建检测。
